## What Was Done

### Azure Embedding Integration

- **Created `src/azure_embedding.py`** (~160 lines):
  - `AzureOpenAIEmbeddingFunction` class implementing the ChromaDB
    `EmbeddingFunction[Documents]` protocol.
  - Uses `openai.AzureOpenAI` client for embedding calls.
  - `create_azure_embedding_function()` factory reads env vars
    (`AZURE_OPENAI_ENDPOINT`, `AZURE_OPENAI_API_KEY`, `EMBEDDING_DEPLOYMENT`).
  - `is_available` property for runtime availability checks.

- **Modified `src/chroma_manager.py`**:
  - Added `embedding_function=None` parameter to `__init__`.
  - Passes embedding function to `get_or_create_collection()`.
  - Added fallback handling: if an existing collection has a different
    embedding type, catches the conflict and opens without overriding.

- **Modified `src/main_starter.py`**:
  - Added import of `create_azure_embedding_function`.
  - Creates `self.azure_embedding_fn` in orchestration `__init__`.
  - Passes embedding function to `ChromaDBManager`.
  - Added "Azure Embedding Function" test section in `run_tests()` that
    gracefully handles 404 DeploymentNotFound.
