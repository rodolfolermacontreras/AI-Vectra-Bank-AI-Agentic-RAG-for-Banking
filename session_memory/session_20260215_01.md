## Implementation

### Files created
1. `src/models.py` (~218 lines)
   - `RiskLevel` enum (LOW, MEDIUM, HIGH, CRITICAL)
   - `AccountType` enum (CHECKING, SAVINGS, CREDIT, INVESTMENT, MORTGAGE)
   - `CustomerProfile` with field_validators for credit_score (0-850 clamping)
   - `AgentActivation` dataclass for tracking agent execution
   - `EnhancedBankingReport` with validators for risk_score, financial_health_score, ratios
   - `display()` method for formatted console output

2. `src/data_connector.py` (~305 lines)
   - `DataConnector` class with async `fetch_income()`, `fetch_transactions()`
   - `get_db_connection()` context manager using pyodbc
   - Static `get_sample_transactions()` and `get_sample_income()` fallbacks
   - Customers supported in fallback: 12345, 67890, 11111

3. `src/main_starter.py` (~1400 lines) -- completed from skeleton
   - `EnhancedBankingSequentialOrchestration` class
   - `create_enhanced_agents()` -- 6 ChatCompletionAgent instances
   - Sequential pipeline: Data Gatherer -> Fraud Analyst -> Loan Analyst ->
     Support Specialist -> Risk Analyst -> Synthesis Coordinator
   - `run_enhanced_analysis()` with AgentGroupChat sequential orchestration
   - CLI: `--test` (component validation), `--demo` (single scenario), `--all` (5 scenarios)
   - Callback-based agent response logging

### Seed code copied (not modified)
