# Session Memory

This directory tracks every development session chronologically. Each session
file records what was attempted, what worked, what failed, and what decisions
were made.

## Naming Convention

```
session_YYYYMMDD_NN.md
```

- `YYYYMMDD` -- date of the session
- `NN` -- sequence number if multiple sessions in one day (01, 02, ...)

## How to Use

After each coding session, create or update the session file with:
1. **Goal** -- what you set out to do
2. **Actions** -- what you actually did (commands, files changed)
3. **Results** -- what worked, what failed, error messages
4. **Decisions** -- why you chose a particular approach
5. **Next steps** -- what to do in the next session
