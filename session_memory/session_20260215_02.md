### 1. Emoji and Unicode Cleanup
Removed all emoji and non-ASCII characters from `src/` files per DEVELOPMENT_RULES.

**src/main_starter.py changes:**
| Line(s) | Before | After |

| Separator chars | `\u2501` (bold box) | `=` (ASCII equals) |

| Report saved | `\U0001f4c4` (page emoji) | removed |
| Em-dashes | `\u2014` | `--` |
| Ellipsis | `\u2026` | `...` |
| Truncation msg | `\u2026 ({n} more)` | `... ({n} more)` |

**src/models.py changes:**
| Line | Before | After |
